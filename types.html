The 16 Myers-Briggs Personality Types

The Myers-Briggs Type Indicator (MBTI) organises personality into 16 types across four dimensions: Energy, Perception, Judgement, and Lifestyle. Each type is a lens, not a label - a way of understanding how you think, decide, and relate to the world.

The 16 types are grouped into four temperaments: NF Idealists (INFP, ENFP, INFJ, ENFJ), NT Rationals (INTJ, ENTJ, INTP, ENTP), SP Artisans (ISFP, ESFP, ISTP, ESTP), and SJ Guardians (ISFJ, ESFJ, ISTJ, ESTJ). Each temperament shares core motivations and cognitive patterns. Explore any type above for a full Myers-Briggs profile including cognitive functions and compatibility.
